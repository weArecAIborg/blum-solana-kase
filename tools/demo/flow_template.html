What runs on Solana, step by step

Every step of the bond's life is one Solana transaction. For each: who may send it, which programs ran in which order (a program calling another is indented under it), every account each one used with its role, what the program checks before it acts, and which balances changed. Each example is a real transaction of the 8-holder devnet run.

Every bond movement runs through bond_servicing

One row per step, top to bottom in the bond's order. Columns: who may send the step, then the programs. Arrows: the calls between them in the order the runtime ran them, read from the transactions below; an arrow into bond_servicing is green. In a transfer, the holder calls Token-2022 and Token-2022 calls bond_servicing back: the arrow pointing left. In this run the registrar's wallet paid every fee.

AllPlay walks through the steps: each row lights up and draws its calls in the order they ran. Prev, Next or the slider pick one step; All shows every row.
