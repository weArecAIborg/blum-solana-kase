Экран оператора

Выпустите облигацию со своими условиями. Корпоративные действия известны из условий выпуска: каждое выполняется само в свой момент, если стоит галка «авто», или по шагам кнопками. Держатели торгуют между собой через Solana DvP, как в документации Solana: сделку записывает и рассчитывает площадка (settlement authority), registrar как transfer agent только допускает escrow сделки в реестр, каждая сторона сама кладёт свою часть. У каждой отсечки есть сделки за день до неё, в её момент и через день. Оператор видит сделки в реестре и ledger. В конце ончейн аудит проверяет каждую выплату по открытым данным; тот же аудит можно запустить у себя одной командой.
