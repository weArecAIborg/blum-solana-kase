# Devnet evidence: B1 terms, 1000 holders

Scenario `scenarios/devnet-crowd-1000.json`, generated by `tools/scenario/make_crowd.py 1000 20261008 20
devnet-crowd-1000` (seeded: placements of 1-20 bonds, 200 trades after each of the first three record moments, a
buyback after record moment 0, a tender offer open across record moment 2). Run
2026-10-11, 02:51-07:06 UTC, by `scripts/run-devnet.sh crowd-1000`; 1 bond day = 20
chain seconds. The run has its own test cash token (6 decimals, mirrors USDC); all amounts are in it.
